# Infotecs-2026

Консольная утилита для асинхронной проверки доступности серверов и замера времени ответа по HTTP/HTTPS.

## Требования

* Python 3.8+
* Зависимости из `requirements.txt` (`aiohttp`)

## Установка

```bash
pip install -r requirements.txt
```

## Ключи запуска

* `-H`, `--hosts` — Список URL через запятую (`[https://ya.ru](https://ya.ru),[https://google.com](https://google.com)`).
* `-F`, `--file` — Путь к файлу со списком URL (по одному на строку).
* `-C`, `--count` — Количество запросов на каждый хост (по умолчанию: `1`).
* `-O`, `--output` — Путь к файлу для сохранения отчета (по умолчанию: вывод в консоль).

*Примечание: Флаги `-H` и `-F` взаимоисключающие.*

## Примеры использования

**Тестирование хостов из командной строки:**

```bash
python bench.py -H https://ya.ru,https://google.com -C 5

```

**Чтение из файла и сохранение отчета:**

```bash
python bench.py -F urls.txt -C 10 -O result.txt

```

## Пример вывода

```text
----------------------------------------
Host: https://ya.ru
Success: 10
Failed: 0
Errors: 0
Min: 0.2970s
Max: 0.4060s
Avg: 0.3515s
----------------------------------------

```
